# تست‌های مرورگری کارگاه ریف

این تست‌ها برنامه را در Chromium باز می‌کنند (با Playwright) و بخش‌های اصلی را واقعاً اجرا می‌کنند. برنامه به این پوشه نیازی ندارد؛ فقط برای توسعه است.

| تست | چه چیزی را می‌سنجد |
|---|---|
| `scales` | ۳۱ مُد اصلی و ۴۸ اسکیل، انتخاب از پنجره‌ی کلید و مُد، لایه (مثلاً Minor blues)، ماندن بعد از بارگذاری، انگلیسی |
| `odd-meters` | همه‌ی ۷۴۴ الگوی میزان لنگ دقیقاً یک میزان و روی دسته‌اند؛ شمارنده‌ی زنده؛ کسر `/16` در ویرایشگر |
| `chord-ideas` | ۸ ایده برای هر آکورد دیاتونیک در همه‌ی مُدها؛ باز شدن از کارت آکورد و از پیشرفت‌ها |
| `idea-append` | ساختن پیشرفت Amaj7#11 → B6 → C#m با آرپژ: هر ایده به آخر ریف اضافه می‌شه، نت‌ها درست‌اند، «برگردون» فقط آخری رو حذف می‌کنه، حالت «جایگزین» |
| `guitar-pro` | خروجی `.gp` از ۷۶۳ ریف و خواندن دوباره با alphaTab؛ نت‌ها، میزان‌ها و تکنیک‌ها یکسان؛ دانلود واقعی |
| `recording` | ضبط با میکروفون مجازی روی بکینگ، پخش، دانلود WAV |
| `tunings` | ۴۶ کوک × همه‌ی مولدها؛ عوض کردن کوک از رابط کاربری (۷ سیم، Drop D، کوک دلخواه)؛ تمپوی ۲۰ تا ۳۰۰ |

## اجرا

```bash
cd riff-workshop/tools/tests
npm install
npx playwright install chromium   # فقط بار اول
bash run.sh              # همه
bash run.sh scales tunings   # فقط چندتا
```

خروجی هر تست `PASS` یا `FAIL` است. تصویرها و فایل‌های ساخته‌شده (`.gp`، `.wav`) در پوشه‌ی موقت `riff-tests` سیستم ذخیره می‌شوند (با `OUT=...` عوضش کن).

**قبل از هر کامیت که به منطق برنامه دست می‌زند، `bash run.sh` را اجرا کن.** اگر قابلیت جدیدی اضافه کردی، برایش یک فایل `*.test.js` هم بنویس که در صورت خطا `fail('...')` را صدا بزند.
